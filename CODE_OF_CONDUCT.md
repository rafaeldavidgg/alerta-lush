# Código de conducta

## Nuestro compromiso

Queremos un espacio acogedor y libre de acoso para todas las personas, sin importar edad, tamaño corporal, discapacidad visible o invisible, etnia, sexo, identidad o expresión de género, experiencia, educación, estatus socioeconómico, nacionalidad, apariencia, raza, religión u orientación sexual.

## Nuestras normas

Comportamientos que contribuyen a un entorno positivo:

- Usar lenguaje acogedor e inclusivo.
- Respetar puntos de vista y experiencias diferentes.
- Aceptar con elegancia las críticas constructivas.
- Centrarse en lo mejor para la comunidad.
- Mostrar empatía hacia otros miembros.

Comportamientos inaceptables:

- Lenguaje o imágenes sexualizadas y atención sexual no deseada.
- Comentarios despectivos, insultos o ataques personales o políticos.
- Acoso público o privado.
- Publicar información privada de terceros sin permiso.
- Cualquier conducta inapropiada en un entorno profesional.

## Aplicación

Los comportamientos abusivos, acosadores o inaceptables pueden ser moderados con advertencias, expulsión temporal o permanente del proyecto, según la gravedad.

Para reportar un incidente, usa la vía privada de _Security_ de GitHub (_Report a vulnerability_) o abre una issue genérica pidiendo contacto, sin exponer datos sensibles. Todos los reportes se tratarán con confidencialidad.
